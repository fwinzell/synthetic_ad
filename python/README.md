Python code used for the publication: Winzell, Filip, et al. "Benchmarking privacy and utility in synthetic tabular cohorts for Alzheimer's disease research." Alzheimer's & Dementia: Diagnosis, Assessment & Disease Monitoring 18.3 (2026)

Note, to run this package you need to install DataSynthesizer: https://github.com/DataResponsibly/DataSynthesizer
Either clone the repo to this folder or use `pip install DataSynthesizer`
This is not included in the requirements file since historically it did not support pip install
